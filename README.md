# MotivationAI
[Presentation](https://docs.google.com/presentation/d/18jI0X78f7tIx9GcfRTJ9KRN_4IJ7PE7Ex6F2QZks-Bs/edit?usp=sharing) 
AI-powered habit tracking and motivation system with gamification elements.

## Overview

MotivationAIApp is an application designed to help users build habits and stay motivated through personalized recommendations, progress tracking and gamification mechanics.

The project combines backend services, AI-powered workflows and habit formation principles to create a more engaging productivity experience.

---

## Features

* Habit tracking
* Streak system
* Achievement mechanics
* Personalized motivation
* AI-generated recommendations
* Event system
* User progress analytics

## Run Locally

```bash
git clone https://github.com/evashka28/MotivationAIApp.git
cd MotivationAIApp
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the server:

```bash
uvicorn app.main:app --reload
```
